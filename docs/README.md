# MindLog

個人の思考・記録（出来事、反省点、学び、気付き、悩みなど）を整理・言語化するためのWebアプリケーション。単純な日記アプリではなく、記録の目的に応じて「問題解決」「日記」「1日の振り返り」の3つのモードを選択できる点が特徴。

バックエンドは Java + Spring Boot、DBはMySQL、フロントエンドはHTML／CSS／JavaScript＋Reactを使用する（[要件定義書](requirements/requirements.md) 参照）。

## プロジェクトの目的

アプリを完成させることだけでなく、実務に近い開発工程を経験することを重視するプロジェクト。ソースコード・設計書はGitHubで管理する。

## 開発工程

```
要件定義 → 基本設計 → 詳細設計 → DB設計 → 環境構築 → 実装 → テスト → GitHub管理 → レビュー → 改善
```
