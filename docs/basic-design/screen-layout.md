# MindLog 画面レイアウト

## 0. 文書情報

| 項目 | 内容 |
|---|---|
| 文書名 | MindLog 基本設計書：画面レイアウト |
| バージョン | v1.0 |
| 作成日 | 2026-10-08 |
| ステータス | 確定 |
| 関連文書 | [要件定義書](../requirements/requirements.md)、[画面遷移図](screen-transition.md)、[ER図](er-diagram.md) |

本書は各画面に「何を」「どの順で」配置するかを定める。色・フォント・余白などの見た目の詳細は実装時に調整する。

- 画面IDは[画面遷移図](screen-transition.md)の SC-xx に対応する。
- 図中の `[ボタン]` はボタン、`____` は1行入力欄、`┌─┐` で囲んだ領域は複数行入力欄（テキストエリア）を表す。
- 要件定義書・画面遷移図に記載がなく本書で決定した事項は [10. 基本設計で決定した事項](#10-基本設計で決定した事項) にまとめる。

## 1. 共通部品

### 1.1 共通ヘッダー（SC-03〜SC-08）

```
MindLog                                   [ダッシュボード] [ログアウト]
──────────────────────────────────────────────────────────────────
```

| 要素 | 種類 | 動作 |
|---|---|---|
| MindLog | テキスト | アプリ名の表示のみ |
| ダッシュボード | リンク | SC-03 へ遷移 |
| ログアウト | ボタン | ログアウトし SC-01 へ遷移。確認ダイアログは出さない |

### 1.2 表示ルール

| 対象 | ルール | 根拠 |
|---|---|---|
| タイトル未入力の記録 | 「（無題）」と表示する（入力欄では空欄のまま） | 要件定義書7節 |
| 対象日 | `YYYY-MM-DD` 形式（例：2026-10-08） | - |
| 作成日時・更新日時 | `YYYY-MM-DD HH:mm` 形式（例：2026-10-08 21:30） | - |
| モード | 「問題解決」「日記」「1日の振り返り」の日本語名で表示する | FR-009 |

## 2. SC-01 ログイン画面

```
                      MindLog

  ┌ メッセージ表示エリア ─────────────────────────┐
  │ （登録完了時）ユーザー登録が完了しました。ログインしてください。
  │ （失敗時）メールアドレスまたはパスワードが正しくありません。
  └──────────────────────────────────────────┘

  メールアドレス   ______________________
  パスワード       ______________________

                    [ログイン]

          アカウントをお持ちでない方は 新規登録
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| メッセージ表示エリア | テキスト | 登録完了時・ログイン失敗時のみ表示。登録完了の文言は上記のとおり | FR-002, FR-003 |
| メールアドレス | 1行入力 | | FR-001 |
| パスワード | 1行入力（伏せ字） | | FR-001 |
| ログイン | ボタン | 成功時 SC-03、失敗時は本画面を再表示 | FR-001, FR-003 |
| 新規登録 | リンク | SC-02 へ遷移 | - |

## 3. SC-02 新規登録画面

```
                    新規ユーザー登録

  メールアドレス           ______________________
                           ※エラーメッセージ（該当時）
  パスワード               ______________________
                           8文字以上、英字と数字を含めてください
                           ※エラーメッセージ（該当時）
  パスワード（確認）       ______________________
                           ※エラーメッセージ（該当時）

                       [登録する]

               ログイン画面へ戻る
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| メールアドレス | 1行入力 | 形式不正・重複時はエラー表示 | FR-002, FR-004 |
| パスワード | 1行入力（伏せ字） | 入力ルールの説明を常に表示する。ルール違反時はエラー表示 | FR-002, FR-004 |
| パスワード（確認） | 1行入力（伏せ字） | パスワードと不一致時はエラー表示 | FR-002, FR-004 |
| エラーメッセージ | テキスト | 各入力欄の直下に表示する | FR-004 |
| 登録する | ボタン | 成功時 SC-01（登録完了メッセージ表示）、失敗時は本画面を再表示 | FR-002, FR-004 |
| ログイン画面へ戻る | リンク | SC-01 へ遷移 | - |

## 4. SC-03 ダッシュボード

```
（共通ヘッダー）

  [＋ 新しく記録する]

  最近の記録
  ┌───────────┬────────────────────┬───────────┬──────────────────┐
  │ 対象日     │ タイトル             │ モード      │ 更新日時           │
  ├───────────┼────────────────────┼───────────┼──────────────────┤
  │ 2026-10-08 │ 仕事の段取りの見直し │ 問題解決    │ 2026-10-08 21:30 │
  │ 2026-10-08 │ （無題）             │ 日記        │ 2026-10-08 20:15 │
  │ …（最大5件）                                                    │
  └───────────┴────────────────────┴───────────┴──────────────────┘
  （記録が0件の場合）まだ記録がありません。

                                         すべての記録を見る →
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| 新しく記録する | ボタン | SC-04 へ遷移 | FR-016 |
| 最近の記録 | 一覧 | 更新日時の新しい順に最大5件。表示項目は対象日・タイトル・モード・更新日時 | FR-017 |
| 最近の記録の各行 | リンク | 選択した記録の SC-07 へ遷移 | - |
| 0件時メッセージ | テキスト | 「まだ記録がありません。」 | - |
| すべての記録を見る | リンク | SC-06 へ遷移 | FR-016 |

## 6. SC-05 記録作成画面

モードによって入力項目のみが異なる。以下は「問題解決」の例。

```
（共通ヘッダー）

  新しい記録（問題解決）

  対象日     [2026-10-08 ▼]
  タイトル   ________________________________________

  目標
  ┌──────────────────────────────────────┐
  │                                          │
  └──────────────────────────────────────┘
  現状
  ┌──────────────────────────────────────┐
  │                                          │
  └──────────────────────────────────────┘
  （ギャップ・原因・対策も同様に並ぶ）

  [キャンセル]                                    [保存する]
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| モード名 | テキスト | 見出しに選択中のモードを表示する。本画面ではモードを変更できない | FR-009 |
| 対象日 | 日付入力 | 初期値は当日。変更可能 | FR-011 |
| タイトル | 1行入力 | 任意 | FR-006〜FR-008 |
| モード別入力項目 | 複数行入力 | 任意。下表のとおり | FR-006〜FR-008 |
| キャンセル | ボタン | 保存せず SC-04 へ遷移 | - |
| 保存する | ボタン | 保存後、作成した記録の SC-07 へ遷移 | FR-006〜FR-008 |

モード別入力項目（タイトル以外。上から表示順）：

| モード | 入力項目 |
|---|---|
| 問題解決 | 目標、現状、ギャップ、原因、対策 |
| 日記 | メモ |
| 1日の振り返り | 今日の出来事、反省点、学び、気付き、明日やること |

## 7. SC-06 記録一覧画面

```
（共通ヘッダー）

  記録一覧

  ┌ 検索条件 ──────────────────────────────────────────┐
  │ モード     [指定なし ▼]                                  │
  │ 対象日     [開始日 ▼] 〜 [終了日 ▼]                      │
  │ タイトル   ______________________                        │
  │                                     [クリア]  [検索]     │
  └──────────────────────────────────────────────┘
  ※開始日は終了日以前の日付を指定してください。（エラー時）

  ┌──────────┬──────────────┬─────────┬────────────────┬────────────────┐
  │ 対象日    │ タイトル        │ モード    │ 作成日時          │ 更新日時          │
  ├──────────┼──────────────┼─────────┼────────────────┼────────────────┤
  │ 2026-10-08│ 仕事の段取り…   │ 問題解決  │ 2026-10-08 21:00 │ 2026-10-08 21:30 │
  │ …                                                                         │
  └──────────┴──────────────┴─────────┴────────────────┴────────────────┘
  （0件の場合）該当する記録がありません。

  [ダッシュボードへ]
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| モード | 選択 | 指定なし／問題解決／日記／1日の振り返り | FR-021 |
| 対象日（開始日・終了日） | 日付入力 | 両方入力時のみ有効。片方のみの入力は不可 | FR-022 |
| タイトル | 1行入力 | 部分一致 | FR-024 |
| クリア | ボタン | 検索条件をすべて空にし、全件を表示する | - |
| 検索 | ボタン | 指定した条件のAND検索 | FR-020 |
| エラーメッセージ | テキスト | 開始日＞終了日の場合に表示し、検索を実行しない | FR-023 |
| 記録一覧 | 一覧 | 対象日・タイトル・モード・作成日時・更新日時。更新日時の新しい順 | FR-018 |
| 一覧の各行 | リンク | 選択した記録の SC-07 へ遷移 | - |
| 0件時メッセージ | テキスト | 「該当する記録がありません。」 | FR-025 |
| ダッシュボードへ | ボタン | SC-03 へ遷移 | - |

ページング（1ページあたりの表示件数の制限）は初期実装では行わず、全件を表示する。

```
（共通ヘッダー）

  仕事の段取りの見直し                         [編集] [削除]

  モード     問題解決
  対象日     2026-10-08
  作成日時   2026-10-08 21:00
  更新日時   2026-10-08 21:30

  目標
    （入力内容）
  現状
    （入力内容）
  ギャップ / 原因 / 対策
    （入力内容）

  [一覧へ戻る]
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| タイトル | テキスト | 未入力時は「（無題）」 | FR-019, 要件定義書7節 |
| モード・対象日・作成日時・更新日時 | テキスト | | FR-019 |
| モード別入力項目 | テキスト | 項目名と入力内容を表示。未入力の項目も項目名は表示し、内容は空欄とする | FR-019 |
| 編集 | ボタン | SC-08 へ遷移 | FR-014 |
| 削除 | ボタン | 削除確認ダイアログを表示 | FR-015 |
| 一覧へ戻る | ボタン | SC-06 へ遷移 | - |

```
  ┌──────────────────────────┐

  │                              │
  │        [キャンセル] [削除]   │
  └──────────────────────────┘
```

| 要素 | 種類 | 内容・動作 | 関連要件 |

## 9. SC-08 記録編集画面

SC-05（記録作成画面）と同じ構成で、以下が異なる。

```
（共通ヘッダー）

  記録の編集（問題解決）

  対象日     [2026-10-08 ▼]        ← 現在の値を初期表示
  タイトル   仕事の段取りの見直し__  ← 現在の値を初期表示
  （モード別入力項目も現在の値を初期表示）

  [キャンセル]                                    [保存する]
```

| 要素 | 種類 | 内容・動作 | 関連要件 |
|---|---|---|---|
| 各入力項目 | - | 現在の値を初期表示する。タイトル未入力の記録は空欄で表示する（「（無題）」は入れない） | FR-014 |
| モード | テキスト | 編集画面ではモードを変更できない | - |
| キャンセル | ボタン | 保存せず SC-07 へ遷移 | - |
| 保存する | ボタン | 保存後 SC-07 へ遷移 | FR-014 |

## 10. 基本設計で決定した事項

| No. | 項目 | 決定内容 |
|---|---|---|
| 1 | 編集時のモード変更 | 変更不可とする（モードを変えたい場合は新しく作成する）。モードを変えるとモード別テーブルの移し替えが必要になり、入力項目も対応しないため |
| 2 | ダッシュボード「最近の記録」の表示項目 | 対象日・タイトル・モード・更新日時（一覧画面から作成日時を除いたもの） |
| 3 | ダッシュボードの0件時表示 | 「まだ記録がありません。」と表示する |
| 4 | 日付・日時の表示形式 | 対象日は `YYYY-MM-DD`、作成日時・更新日時は `YYYY-MM-DD HH:mm` |
| 5 | 新規登録画面のエラー表示位置 | 各入力欄の直下に表示する（ログイン画面は理由を個別に出さないため、フォーム上部にまとめて表示） |
| 6 | 登録完了メッセージの文言 | 「ユーザー登録が完了しました。ログインしてください。」 |
| 7 | モード選択画面の説明文 | 各モードボタンに用途の説明文を添える |
| 8 | 記録一覧の検索条件クリア | 「クリア」ボタンを置く |
| 9 | 記録一覧のページング | 初期実装では行わず全件表示する |
| 10 | 詳細画面での未入力項目の表示 | 項目名は表示し、内容は空欄とする |
| 11 | ログアウト時の確認 | 確認ダイアログは出さない |
